# Theme System

> 已确认导入与安全策略；关键对比度修正算法已锁定（见第4节）。Token 到组件的完整映射表仍按实现验证。

## 1. 导入边界

- V1 只提供用户手动导入 Zed Theme Family JSON，包括 Rainbow。
- 原始 JSON 复制到 `%LOCALAPPDATA%\ohMyWork\themes\<import_uuid>\source.json`，并写 `metadata.json`。
- 不自动扫描 Zed themes/extensions，不监听来源路径；来源移动不影响已导入副本。
- 重新导入才更新；来源文件始终不修改。
- Theme Family 可含多个 light/dark 成员；重名、更新与选择规则需定义。

## 2. 内部模型

组件只消费稳定的 ohMyWork 语义 Token，不直接依赖 Zed style 键。版本感知适配器读取已知字段，忽略未知字段，缺失字段确定性回退。

Zed Schema URL（例如 `https://zed.dev/schema/themes/v0.2.0.json`）是外部契约，不意味着固定支持版本或启动时联网下载 Schema。

V1 Token 覆盖窗口/面板/文字/边框、hover/active/selected/focus、错误/警告/禁用、可视化 Markdown/Raw、基础 Task、无限画布和 Pi 面板。日历、终端和图表不因主题格式含字段就进入 V1。

## 3. 应用流程

```text
手动选择 JSON → 校验 → 保留原始副本 → 版本适配
→ 语义回退 → 关键对比度检查/修正 → 内部主题快照 → 应用
```

导入失败不破坏当前可用主题。解析/映射在后台完成，UI 原子应用快照，连续预览的旧结果不覆盖新选择。

支持主题选择、预览/取消与恢复内置安全主题；不提供来源热重载。具体预览 UX 待定。

## 4. 关键 Token 安全覆盖

用户选择了自动安全覆盖，而不是仅警告或直接拒绝：

- 对正文、焦点、选择、错误和禁用等关键语义色检查可读性。
- 颜色空间：sRGB；对比度用 WCAG 2.2 相对亮度。
- 阈值：正文/选中文字 4.5:1；焦点环 3:1；错误相对背景 4.5:1；禁用相对背景与相邻均 3:1，且不得作为唯一状态线索。
- 不合格时相对背景或前景做二分混合，直到达标；只改必要 Token，保留其他气质。
- 展示修正清单（每个被改 token），源 JSON 不改写。
- 始终有键盘可达的安全主题恢复入口。

WCAG 2.2 AA 按各准则适用范围验收；禁用控件不一定适用正文对比度阈值，但仍要求清晰识别。配色修正不能替代完整的键盘、焦点、缩放和辅助技术测试。

## 5. 性能、安全与验证

限制 JSON 文件大小、深度和集合数量，不执行脚本。主题变化不触发 Workspace 重建；无效导入不能留下半应用界面。

验证真实 Rainbow light/dark、缺失/未知字段、未来 Schema、非法颜色、低对比度、名称冲突、来源删除后仍可使用副本、重新导入和安全恢复。

不捆绑未经许可的第三方主题分发。
