# ADR-0008: 纯可视化编辑与明确的保存边界

**Accepted，编辑模式部分已由 ADR-0011 替代**。保存边界 DEC-004 至 DEC-007 继续有效。

## Context

用户选择所见即所得，但仍要求普通 Markdown 为事实来源；保存策略经过立即保存讨论后最终选择 Ctrl+S。同时用户明确外部版本优先，不要求未保存草稿保护。任务组件则需要独立立即提交，不能保存未提交正文。

## Decision

- **DEC-001**：CommonMark + GFM 纯可视化编辑，无源码模式。此编辑模式决定已由 ADR-0011 替代。
- **DEC-002**：未知/无法安全可视化的内容保留为 Raw 节点，可移动/删除但不编辑内部文本。已由 ADR-0011 的整篇源码编辑决定替代。
- **DEC-003**：最小范围写回，不因编辑一个节点而格式化全文。已由 ADR-0011 的直接保存源内容决定替代。
- **DEC-004**：正文 Ctrl+S/保存命令提交；关闭脏内容提供保存/放弃/取消；不持久化未保存草稿。
- **DEC-005**：真正外部修改直接重载并彻底丢弃该文件未保存编辑，没有临时恢复机会或覆盖前询问。
- **DEC-006**：任务组件只立即提交任务范围；其余脏正文保留在内存，不能将自身事件当作外部替换。
- **DEC-007**：提交采用同目录临时文件 + Windows 原子替换并验证源版本；失败不留下半文件。

## Consequences

### Positive

- **POS-001**：编辑表面统一，不要求用户学习两种模式。
- **POS-002**：源文本开放，Raw 和局部写回减少对既有排版的破坏。
- **POS-003**：Pi/外部编辑器的磁盘结果无需逐次人工冲突裁决。

### Negative

- **NEG-001**：外部修改、崩溃或断电可能导致未保存编辑永久丢失。这是用户选择的后果，产品不得暗示有保护副本。
- **NEG-002**：纯可视化 + 局部源文本保留的实现复杂度高于源码编辑器。
- **NEG-003**：Task 单独落盘要求同时维护磁盘基线和脏内存版本，重叠修改需专门处理。
- **NEG-004**：没有源码兜底时，Raw 内部修改需使用外部工具。

## Alternatives Considered

- **ALT-001**：Live Preview 或源码切换。拒绝原因：用户最终选择纯可视化 Markdown。
- **ALT-002**：每次保存规范化全文。拒绝原因：制造不必要差异，增加外部修改冲突。
- **ALT-003**：自动保存/恢复快照。拒绝原因：用户选择 Ctrl+S 且不保存未提交编辑。
- **ALT-004**：外部变更前确认或保留临时本地版本。拒绝原因：用户选择立即彻底丢弃。
- **ALT-005**：Task 操作顺带提交全文。拒绝原因：会隐式保存用户尚未提交的正文。

## Implementation Notes

- **IMP-001**：源范围、版本、自写事件识别必须作为文档服务核心约束。
- **IMP-002**：无法安全定位/合并任务时不能退化为全文覆盖；具体失败 UX 待定。
- **IMP-003**：测试真正外部通知、自写回声、临时文件事件、保存竞争和未完成中文输入。
